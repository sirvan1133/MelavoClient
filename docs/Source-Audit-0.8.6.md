# بررسی سورس Melavo 0.8.5 و اصلاحات 0.8.6

گزارش پیوست با سورس محلی نسخهٔ منتشرشده تطبیق داده شد. ZIP جدیدی همراه متن در دسترس نبود؛ مبنا همان سورس منتشرشدهٔ 0.8.5 است.

## اصلاح‌شده
- Transport: streamSettings اکنون داخل outbound قرار می‌گیرد. کانفیگ‌های قدیمی هنگام آماده‌سازی برای هسته، بدون تغییر دادهٔ اصلی تبدیل می‌شوند. تنظیم موجود داخل outbound اولویت دارد.
- VMess: UUID نامعتبر با خطا رد می‌شود؛ UUID صفر جایگزین نمی‌شود.
- تغییر تم: کش لایهٔ حاشیه بازنشانی و در Classic حذف می‌شود. تست تعویض روشن/تاریک و Glass/Classic پاس شد.
- منوی کلیک راست: عرض 286→200 و ارتفاع ردیف 44→31 واحد منطقی، تقریباً 30٪ کوچک‌تر؛ آیتم‌های گرد و گذار نرم، Connect همچنان اول.
- ساب: ارتفاع صفر عنوان حذف و ردیف‌ها در ارتفاع موجود تنظیم شدند؛ تست حداقل اندازه و عدم همپوشانی پاس شد.
- Timer نظارت: هنگام بسته‌شدن فرم Dispose می‌شود.
- UpdateGroups: نسخه‌های موقت جدا ساخته می‌شوند و فقط پس از ذخیرهٔ موفق جایگزین وضعیت فعلی می‌شوند؛ شکست دریافت دادهٔ گروه اصلی را تغییر نمی‌دهد.
- ZIP دستی: هش آرشیو با digest انتشار همان نسخه در مخزن رسمی GitHub از HTTPS مقایسه می‌شود، سپس فایل‌ها بررسی می‌شوند. تأیید فقط از manifest داخل ZIP نیست. نیاز به اینترنت دارد؛ امضای آفلاین Authenticode/Ed25519 اضافه نشده است.

## موارد گزارش که به‌تنهایی باگ محسوب نمی‌شوند
- حذف border دکمه/Input به درخواست قبلی صاحب برنامه انجام شده بود؛ Penهای بلااستفاده حذف شدند، خط‌های دور ابزارها برگردانده نشدند.
- ثابت بودن سرعت Reflection در hover مطابق مشخصات 10s linear است. پارامتر unused قابل پاک‌سازی است؛ افزایش سرعت لازم نیست.
- ادعای روشن‌تر شدن گوشه‌ها صرفاً از روی تعداد segment ثابت نمی‌شود و نیاز به سنجش تصویر دارد.

## موارد واقعی باقی‌مانده / نیازمند کار جدا
- Reflection برای هر اندازه تا 300 تصویر بریدهٔ کوچک نگه می‌دارد و Warm همزمان انجام می‌شود. این هزینهٔ واقعی است؛ مقدار RAM و افت سرعت باید اندازه‌گیری شود. renderer و cache در این نسخه بازنویسی نشده‌اند.
- شمارش ترافیک SOCKS پیاده نشده؛ نمایش ترافیک فعلی به رابط TUN متکی است. باید آمار هسته/پروکسی اضافه شود؛ شمارش کل کارت شبکه جایگزین درست نیست.
- manifest هنوز requireAdministrator دارد. اجرای بدون ادمین به helper و مسیر ارتقای TUN نیاز دارد؛ تغییر سادهٔ manifest راه‌حل کامل نیست.
- امضای مستقل آفلاین بسته‌ها موجود نیست. هش GitHub، اعتماد به مخزن و HTTPS است و با امضای ناشر برابر نیست.
- DPI: ترکیب اندازه‌های ثابت و Scale وجود دارد؛ تست 125/150/200٪ و مانیتورهای متفاوت برای نتیجهٔ قطعی لازم است. وجود پیکسل ثابت به‌تنهایی اثبات clipping نیست.

## آزمون‌ها
Build Customer: صفر خطا و هشدار.
UI: parsing، legacy migration، UUID خراب، اشتراک‌گذاری، زبان‌ها، منو، تم، layout و navigation پاس شدند.
Update: تشخیص خرابی، traversal و rollback پاس شدند.
آزمون‌ها اتصال واقعی به سرور مشتری را اثبات نمی‌کنند؛ دادهٔ مشتری وارد بسته نشده است.
