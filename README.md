# Melavo VPN

A modern VPN client for Windows and Android, available in English and Persian.

Android 7 or newer. Windows requires [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).

[Download for Windows](https://github.com/sirvan1133/MelavoClient/releases/download/v0.9.2/Melavo-VPN-0.9.2-Windows-x64.zip)

[Download for Android](https://github.com/sirvan1133/MelavoClient/releases/download/v0.9.2/Melavo-VPN-0.9.2-Android-universal.apk)

## فارسی

ملـاوو، یک کلاینت VPN برای ویندوز و اندروید با رابط کاربری مدرن و دو زبان فارسی و انگلیسی است.

اندروید ۷ به بالا. نسخه ویندوز به Microsoft Edge WebView2 Runtime نیاز دارد.
