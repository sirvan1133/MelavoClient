# Melavo VPN

A modern Windows VPN client with a clean interface and support for Xray and sing-box. Available in English and Persian.

Requires [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).

[Download for Windows](https://github.com/sirvan1133/MelavoClient/releases/download/v0.9.2/Melavo-VPN-0.9.2-Windows-x64.zip)

## فارسی

ملـاوو، یک کلاینت VPN برای ویندوز با رابط کاربری ساده و مدرن، پشتیبانی از Xray و sing-box و دو زبان فارسی و انگلیسی است.

برای اجرا به Microsoft Edge WebView2 Runtime نیاز دارد.
